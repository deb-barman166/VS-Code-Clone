🚀 CodeCraft IDE — Advanced Web Code Editor

🔥 A powerful, modern, and fully offline-ready code editor built directly in your browser.
Experience a VS Code-like environment without installing anything.

---

🌟 Live Demo

👉 Try it now:
🔗 https://deb-barman166.github.io/VS-Code-Clone/

---

⚡ Features

- 🧠 Smart Code Editor (Powered by Monaco Editor)
- 📁 Virtual File System (Save files in browser)
- 🎨 Dark & Light Theme
- 📑 Multi-Tab Editing
- 🔍 Global Search Across Files
- ⌨️ Command Palette (Ctrl + Shift + P)
- ✂️ Split Editor View
- 💾 Auto Save System
- 📱 PWA Support (Install as App)
- ⚡ Fast & Offline Ready

---

🛠️ Built With

- HTML5
- CSS3 (Advanced UI System)
- JavaScript (Core Logic)
- Monaco Editor
- IndexedDB

---

🚀 How to Use

1. Open the website
2. Click New File
3. Start coding instantly
4. Your files are auto-saved in browser
